Cost reconciliation

USD · configured estimate → classified provider evidence

Record the attributable provider cost from authenticated provider evidence. Select whether it is a provider cost report/export or an invoice; an open-period report is not an invoice. Verify account, period, currency and request attribution before entry. Do not allocate an aggregate without an approved rule. The usage row and its original ledger entries are never edited: the difference × 1.5 is appended as a reconciliation ledger entry. Credits return to the wallets originally debited; additional charges come from the payer's paid balance or wait as pending_funds.
