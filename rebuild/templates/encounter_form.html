A clear path to your document

  1. Add notes. Use the exact question label and a complete answer: Question label: answer, one per line.
  2. Review. Generate once. Check each answer and quotation; correct it or choose a reviewed blank where offered.
  3. Export. Save your decisions, finalize, then download the original format.
Use labelled answers for this demo.

For documented SOAP facts, use Subjective:, Objective:, Assessment: and Plan: as the exact labels. Omit undocumented sections; missing fields stay blank for review. Free-prose SOAP rewriting is not qualified. Custom Word uses the checked fields in a supported original.

Using voice?

Leave notes empty if you wish, then create the document. On the next page, record or upload audio. Correct the transcript into labelled lines and explicitly save it before generating.

When an answer is held for review

Missing facts stay missing. Conflicts never become normal findings. Write denials explicitly, such as Symptoms: no chest pain.

Question/answer tables, placeholders, PDFs and WM IOV need exact labels. Extra unlabelled lines, empty labels, headings or corrections can hold answers. WM IOV also requires labelled prewritten statements; check its form page.

Underlined-Tab forms accept complete sentences with a recognised verb and final punctuation. Headings, quotations, incomplete sentences or conditional wording can return conflicts. Use labelled answers when possible and review every held field.
