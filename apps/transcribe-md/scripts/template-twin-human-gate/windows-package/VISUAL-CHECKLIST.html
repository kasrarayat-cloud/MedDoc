Microsoft Word observation checklist

COM automation cannot determine repair dialogs or visual/layout correctness. Observe Word and answer every console question. Do not enter patient information or free-form clinical notes.

For every document

  • No repair, unreadable-content, corruption, or conversion-loss dialog appears.
  • Every expected visible synthetic value survives open, save, reopen, and PDF export.
  • Dropdown and checkbox states behave as expected; any flattening is a failure.
  • No expected field disappears, duplicates, moves, or appears under another label.
  • Clinically meaningful static text remains present and unchanged.
  • Tables, cell boundaries, merged cells, headers, and footers remain intact.
  • Margins, fonts, numbering, page breaks, and pagination remain acceptable.

Evidence rules

  • Use PASS only when directly observed.
  • Use FAIL for any observed defect.
  • Use BLOCKED when an item could not be observed.
  • Never infer a pass from automation alone.
