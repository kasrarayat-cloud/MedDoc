QuillMD · SOAP tab redesign · v3 · simple concepts

V3 · 10 SIMPLE · 2026-05-09

Round 3 inverts v2's direction. v2 reached for novel paradigms (diff mode, audit-trail marginalia, opacity-as-confidence, voice-first, AI co-pilot, transcript-link). All clever, none resonated. v3 reaches for clean execution of standard patterns — single column, two-column, cards, accordion, stepper, form, document, side-tabs, grid. A doctor opens the SOAP tab, understands what they're looking at within 2 seconds, knows what to do next without instruction. Reference points: Things 3, Linear's basic issue view, Notion's plain document mode. Same fixture as v2 (Maria Castillo, 52F, T2DM/HTN follow-up, new orthostatic dizziness, dapagliflozin + Lisinopril Rx warning) so layout differences are visible without content noise. Same production token discipline: dark canvas #08090a, sage #7AA68C, Inter + JetBrains Mono. The Rx warning is present in every concept but treated calmly — single-line inline alert or sidebar tile, not a takeover.

Earlier rounds: v1 (5 concepts: Index+Body, Problem-Forward, Hero+Detail, Smart Highlights, Active vs Reference) · v2 (10 concepts: Tabbed, Split-pane, Diff, Confidence-graded, Audit-trail, Compact dashboard, AI co-pilot, Voice-first, Mobile, Print-preview).
