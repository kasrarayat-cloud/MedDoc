QuillMD · Design design/soap-edit-experience-v3 SOAP edit canvas

The editing surface itself · v3

v1 explored where the edit affordance lives. v2 explored what paradigm editing follows. v3 starts with a different premise: the doctor is editing. What does the canvas look and feel like? Ten concepts, each its own aesthetic — focus mode, glassy palette, paper, spatial, IDE‑split — so the differences read at a glance against the current production state shown below.
