## #306 — OWNER-RULING — THE NARROWING STANDS, AND WINDING DOWN GETS ITS OWN DOOR

**STANDING.**

> **An unrecoverable practice is never a legitimate outcome of two ordinary
> clicks.**

The `users_last_owner_guard` narrowing lands as built: exemption 2 counts
RESTORABLE members rather than LIVE ones, refusing only the corner where a
trapped non-owner remains and no restorable owner can rescue the practice.
Suspending a solo OWNER stays legal, because that owner is their own rescuer.

⚠️ **AND THE CAPABILITY IT NARROWS IS NOT DISMISSED — IT IS RE-HOMED.** Winding
a practice down is a real need, and the answer is not to leave it reachable as a
side effect of suspend-then-delete. It becomes **PRACTICE-ARCHIVE**, an ADMIN
lifecycle door: **ONE DECLARED ACT** that archives the practice AND its members
together, restorable, audited — the same row `PRACTICE_ARCHIVED` was deferred
to.

The distinction the ruling turns on: today's path reaches the end state by
**accretion**, one legal click at a time, with no actor ever deciding "this
practice is closing". PRACTICE-ARCHIVE makes that a decision somebody takes,
names, and can undo.

## #308 — OWNER-RULING — THE SHARED TREE MUST TYPECHECK

**STANDING.**

**No dev server runs on the deploy surface.** A resident `next-server` on
`/opt/meddoc-pro` leaves stale generated `.next/types` behind, and the pre-push
hook's typecheck then **refuses every push from the shared tree — including a
branch deletion — naming a file the pusher never touched.**

Three parts:

1. **Identify the resident `next-server`'s owner session and stop it THERE.**
   Not killed from outside: a process on a shared box belongs to whoever started
   it.
2. **Clear the stale gitignored `.next` in the shared tree.**
3. **The hook's typecheck EXCLUDES `.next/types`**, so a generated artifact can
   never refuse a push again.

⚠️ **THE THIRD PART IS THE ONE THAT ENDS THE CLASS.** The first two fix today's
instance; only the exclusion stops the next regenerated artifact doing it again.

⚠️ **CUSTOM-FILE'S — THE HOOK IS THEIRS.** Board filing.
