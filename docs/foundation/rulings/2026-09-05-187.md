## 2 · AUTO-ACCEPTED ROWS ARE VISIBLY DISTINCT, AS **TEXT**, NEVER AS COLOUR

A **provenance word** in the frames' own right-aligned meta column — `auto` /
`you` — beside the confidence. The frames' existing vocabulary and geometry; no
new visual element is invented.

**Why text and not a tint:** it survives greyscale print and colour-vision
deficiency, and it is the *"provenance labels distinct"* the owner ruled at the
start of the arc.

⚠️ **THE HIDDEN ACCESSIBILITY TEXT STAYS TOO.** The two are not alternatives.
The visually-hidden state label restores the parity the pre-conversion section
headings carried for assistive technology; the visible word answers the sighted
reader the hidden text cannot reach. Removing either re-opens half the defect.

**Its origin is a finding, not a preference.** The T2 conversion moved the
decision state out of section headings and onto the row, where it became
`data-state` plus a CSS tint — and `ICD_ROW_STATE_LABEL`, added in the same
slice, was rendered nowhere. Measured on a signed visit: an accepted row and a
held row were **byte-identical in text**, accessible name `null`. WCAG 1.4.1, on
the surface a doctor attests from.

## (a) — OWNER-CLASS: A 40001 IS NOT A VANISHED MANIFEST

**The defect.** `sign/route.ts` signs inside a `Serializable` transaction. A
concurrent coding decision on the same visit is enough for Postgres to abort it
with SQLSTATE **40001** (Prisma `P2034`), and that abort fell into the blanket
manifest-fallback catch, which signs the note **STYLED** and stamps
`frozen_manifest_vanished`.

Neither half is true and neither is recoverable: the manifest never vanished
(`resolveFrozenPointer` had just returned it), and a visit signed styled is
styled **forever** — canon 02 records that there is no re-attestation path. So a
doctor loses their own letterhead because somebody clicked a code at the wrong
moment, and the audit row plus the doctor-facing notice both name a cause that
did not happen.

**The fix.** The catch distinguishes serialization failures from a genuinely
vanished manifest: **retry the transaction, bounded**, keeping the pointer;
**never fall to styled on a 40001**; exhausted retries **refuse with a 409**.
Armed with a forced 40001.

⚠️ **The fix is deliberately NARROW.** A genuinely broken freeze is what the
styled fallback is for; narrowing it to nothing would trade one silent harm for
a refused signature on a real manifest failure.

## (b) — `gate-f30`'s FLAKE

The cwd arm compared two full stdout strings and the sweep makes **live
`git ls-remote` calls** whose result reaches stdout twice — the controls line,
and the bucket assignment. It varied two things and attributed both to one; the
network-dependent-output class, already filed.

**Make the arm print its diff on failure and remove the live network result
from the compared output.**
