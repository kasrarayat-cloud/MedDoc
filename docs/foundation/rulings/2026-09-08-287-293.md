## #287 — OWNER-RULING — `DL-2`, CLASS (a), DECIDED: THE CHART'S PRACTICE OWNS THE TEMPLATE TOO

**STANDING.**

> **A visit is documented in the TENANT practice's format.** A locum from B
> seeing A's patient fills **A's active template**; B's template never fills a
> visit in A.

**SO THE PARAMETER SPLITS**, and each half is named for the question it answers:

| parameter | what it does |
|---|---|
| `tenantPracticeId` | scopes the visit **AND** selects/validates the template — provenance compares the template's owner against the **TENANT** |
| `authorUserId` | who ACTED: audit and attribution. **Never a scope.** |

⚠️ **AND THE MISSING-TEMPLATE CASE IS A NAMED OUTCOME, NOT AN ERROR.** If the
tenant has no active template the visit has **no twin fill** — a styled export
with a **named reason**, never a `TEMPLATE_PROVENANCE_MISMATCH`. A mismatch
error is what the old shape produced for a state that is ordinary.

**ARM:** the locum visit, with the three-identity fixture, renders **A's** form.
