door SERIALIZABLE → 40001 refused. **The control is why it is readable at all** —

## #234 — OWNER-RULING — #227's FALSE DECLARATION IS FIXED BY VARYING, NOT BY RE-DECLARING

**STANDING.**

Round five demonstrated that `INTENTIONAL_CONSTANTS`' only entry —
`rowPrototype: 'prototypes never offer'` — is **measurably false**: a
repeating-section prototype **is** offered, and it resolves through the very
branch the matrix is about. The false entry bought a **37/37 green** over a
planted offered-but-not-honoured lie.

> **DO NOT RE-DECLARE. The declaration was not badly worded; it was wrong.**

**THE FIX IS THREE PARTS:**

**(a) VARY `rowPrototype`, and assert the property the declaration was reaching
for.** A repeating-section prototype must never be **OFFERED**. This is the
**#192 rule arriving one surface later**: a prototype must not clone its text
into every row, and that applies to the *offer* exactly as it applied to the
*keep*. The matrix varies the dimension; a separate arm asserts the rule.

⚠️ **THE DECLARATION MECHANISM IS NOT AT FAULT AND IS NOT WEAKENED.** #227's
three states — varied, declared, or RED — are correct. What failed is that a
declaration is only as good as the claim inside it, and **this house's own
standard says a claim is measured, not asserted.** The allowlist stays; it
simply must not carry a claim nobody measured.

**(b) `isVaried` KEYS ON THE `(object, property)` PAIR, NOT THE PROPERTY NAME.**
`mapping.unknownPolicy` is constant across all 3456 rows and the arm reported it
varied — because `field.unknownPolicy` is varied and the two share a name. A
property name is not an identity.

**(c) `READS_RE` COVERS EVERY READ SPELLING THE EXTRACTOR CAN NAME.**
Destructuring, bracket access, a nested binding read and a module-local helper
are all invisible to the current two alternatives, so *"a guard added without
its dimension reds HERE"* is false for four shapes. **Enumerate the spellings
the extractor can produce and cover them, rather than adding the one that was
caught.**

## #235 — OWNER-RULING — THE SIGN/OVERRIDE RACE IS ITS OWN CLINICAL-PATH ITEM: **SIGN-PTR-1**

**STANDING. It is NOT folded into #1018.**

The residue that survived the retraction is real and it is **pre-existing on
`main`** — `sign/route.ts`, `sign-freeze.ts` and `native-export.ts` are untouched
by #1018. Folding it into that PR would attribute a main-line defect to a branch
that **improves** the surrounding behaviour, and would hold a good change hostage
to an unrelated one.

**THE NAMED HARM IS NOT THE FREEZE.** It is this:

> **The door returns `ok:true` and writes a `DEFAULT_INSERTED_BY_DOCTOR` audit
> row asserting a default reached a document it did not reach.**

A trail that asserts a clinical act which did not occur is worse than a missing
trail, because it is evidence pointing the wrong way.

**THE FIX IS PAIRED, AND BOTH HALVES ARE REQUIRED:**

1. **The frozen pointer is resolved INSIDE `signWrite`** — so the override read
   becomes a tracked read at all.
2. **AND the option door is made SERIALIZABLE** — because *one edge is not a
   cycle*. Postgres SSI aborts on a cycle; a READ COMMITTED reader takes no
   predicate lock, so the return edge is never recorded and the sign commits
   regardless. **ARM A measured exactly this.**

> **You cannot buy serializability for a PAIR by upgrading only the side you
> happen to be editing.**

**THE REPRODUCTION IS THE HARNESS'S INTERLEAVE**, kept with the item — including
the correction that its 4-second hold is not the code's window. The window is
real and narrow; the harness made it wide to see it.

**OWNERSHIP IS SPLIT AND THE CHANGE IS PAIRED:**

| lane | owns |
|---|---|
| **Custom-file** | `sign/route.ts`, `native-export.ts` |
| **Design/Admin** | the option door |

⚠️ **NEITHER HALF SHIPS ALONE.** Half of this fix is ARM A — the shape that
measured as *not working*. A paired change across two lanes needs both rows in
one composed deploy, not two independent merges.

⚠️ **REACHABILITY, STATED SO THE PRIORITY IS HONEST:** one CERTIFIED active
compiled version qualifies (53/53 scaffolded) and it has **0 visits**;
`template_twin_field_overrides` has **0 rows, ever**. The race additionally needs
a concurrent sign on the same visit inside a sub-second window. **Real, filed,
and not an emergency.**
