**STANDING. Own PR.**

> **Every index row in the `RULINGS.md` head is a POINTER — number, date, title,
> body path — and the bodies live in `docs/foundation/rulings/`.**

**STANDING rows STAY IN THE HEAD as pointers, never as prose.** That is what
takes the head under budget **without archiving a standing rule** — the outcome
the rotation script could not reach, because it could only move whole arcs out
and a standing rule must remain visible where sessions look for it.

⚠️ **AND `rotate-ledger.sh` BECOMES ATOMIC.** It currently mutates the file and
*then* refuses: its RULINGS pass wiped the archive index (4 archives → 0) before
aborting, and its RELAY pass printed **✔ SUCCESS** while doing the same.

> **Write a temp copy, run the ledger gates ON IT, swap only if they pass —
> otherwise REFUSE BEFORE TOUCHING ANYTHING.**

**With a control that plants a mid-run refusal and asserts the file is
BYTE-UNTOUCHED.** A script that half-applies is not fixed by making the failure
rarer; it is fixed by making the failure incapable of reaching the file.

## #279 — OWNER-RULING — V3'S FAILING INPUT IS THE INSERT RACE

**STANDING.**

The attempt to close `V3` moved the advisory lock after its own count and got
**0/12** on the DEMOTION race — because `FOR UPDATE` on the sibling rows already
serialises that path.

> **The failing input for lock ORDER is the INSERT race, not the demotion race.
> Run the moved-lock mutation against `raceB` — insert-a-member versus
> suspend-a-solo-owner. If it reds, THAT RACE WITH THAT MUTATION IS THE ORDER
> ARM.**

⚠️ **THE REASON IT MUST BE THE INSERT PATH IS ALREADY RECORDED:** a phantom
cannot be locked, which is `MIG-2` and `DOOR-2`. Where `FOR UPDATE` has nothing
to grip, the advisory lock is the only ordering that exists — so that is the only
place its position can be load-bearing.

## #282 — OWNER-RULING — THE WORKTREE MIRROR REFUSES A REAL-DIRECTORY DESTINATION

**STANDING. Filed by the custom-file session.**

`ln -sfn SRC DST` **nests the link INSIDE `DST` when `DST` is a real directory**,
and reports success. `setup-worktree.sh` only ever removed a SYMLINK
destination, so run against a tree that already had a real install it **damaged
680 packages** — and with `-f` it overwrote a real file with a link to a
directory, which is what broke `decimal.js`.

> **The mirror REFUSES on a real-directory destination, NAMING it. With a
> control that plants one.**

⚠️ **AND IT REPORTED `🟢 linked N entries` THROUGHOUT** — the *"a script that
prints a number it does not act on"* family, where the number counted intentions.
