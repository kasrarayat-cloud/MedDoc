## #258 — OWNER-RULING — NO MIRROR

**STANDING. This ends a class rather than closing an instance.**

Round seven found an **EIGHTH** unmirrored `missingResolution` call site — a
checkbox with a multi-concept `conceptScope`, OFFERED an omit control the
resolver will not honour. It is the eighth because the offer predicate
**re-implements** the resolver's decision, and every new resolver branch is a new
opportunity to forget.

> **`scaffoldDefaultOfferable` CALLS the resolver's own `missingResolution`
> predicate — the real function, exported — on the same inputs. The eighth call
> site, and any ninth, cannot exist.**

⚠️ **SEVEN ROUNDS OF ARMS DID NOT CLOSE THIS AND COULD NOT.** Every previous
repair widened a matrix so the mirror's *current* divergences were visible. That
is the wrong shape: a mirror is a second implementation, and a second
implementation of a rule is a defect that testing can only ever *find*, never
prevent. **The tests were being asked to do the job the code should do.**

**THE ARM CHANGES SHAPE WITH IT.** The biconditional stops being a
cross-product that hunts for divergence — there is nothing left to diverge — and
becomes:

1. an **identity check** that the offer DELEGATES rather than decides, and
2. **one behavioural control per known guard**, so delegation to the wrong
   function, or to a stub, still reds.

## #259 — OWNER-RULING — THE MATRIX IS REDESIGNED, NOT RE-SEEDED

**STANDING.**

The seeded sample failed in four ways at once, and re-seeding fixes none of them:
its first guard killed **73.4%** of rows so the two inputs it was widened to
watch were **constant everywhere the other seven guards live**; its generator
saturates at **6.42% of the cross-product forever**; its coverage arm is a
tautology that **passes at `SAMPLES = 3`**; and its green is a property of the
seed literal — **correct code REDS on some seeds.**

**THE REDESIGN, and each clause answers one of those:**

1. **ENUMERATE THE EXACT PRODUCT over the read set the Proxy tracer records** —
   the dimensions the function *actually reads*, nothing else. The tracer already
   knows them; the matrix was guessing.
2. **ENUMERATE COMPATIBLE `(kind, dataType)` PAIRS FROM THE COMPILER'S OWN
   TABLE**, never a hand-written type list. ⚠️ **The hand-written list is what
   killed 73.4% of rows: `'date'` had no compatible partner in it at all**, so
   every date row died at guard 1 by construction.
3. **ASSERT BRANCH COVERAGE — every guard witnessed TRUE and FALSE — not row
   coverage.** Rows are not the unit anybody cares about; branches are.
4. **REFUSE — fail, not warn — any stratum witnessed zero times.**
5. **SAMPLE ONLY IF the exact product exceeds a STATED BUDGET**, stratified by
   guard branch with a **per-stratum floor**.

> ⚠️ **AND THE COVERAGE ARM MUST RED AT `SAMPLES = 3`.** That is the acceptance
> test for the arm itself: the present one passes there, which is what makes it
> a tautology rather than a control.
