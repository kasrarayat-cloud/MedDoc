# §2.5 AUTHOR ROWS — the rows-at-PR-open gate

**Written because the gate refused this PR.** That refusal is its first
application and its best one: a gate whose author is exempt is not a gate.

## WHAT THIS CHANGES AT RUNTIME

`scripts/check-pr-rows-file.sh` — a **read-only** CI check. It touches no
database, no container and no clinical record; it reads a git diff and the
filesystem.

## WHAT MUST CHANGE

| # | row | expected |
|---|---|---|
| 1008-1 | a runtime PR with no rows file | **CI fails** |
| 1008-2 | a runtime PR with a rows file | CI passes |
| 1008-3 | a docs-only PR | CI passes, no rows required |

## WHAT MUST **NOT** CHANGE

| # | row | expected | what makes it a FINDING |
|---|---|---|---|
| 1008-4 | anything at runtime in the product | **nothing** | this ships no application code; a moved image behaviour means something else rode |
| 1008-5 | visit / patient / signature counts | unchanged | the standing clinical-count row, never omitted |
| 1008-6 | the check's verdict on a broken base | **exit 2, cannot-tell** | a `0`. A broken instrument must never read as a pass |

## THE DEPLOY EXPECTATION

**Nothing but the image ids.** No migration, no flag, no writer.
