The script correctly ABORTED (`REGISTRY-3 INCOMPLETE — clinical field(s) declined`)
rather than certify around them:

   with NO concept.** POSTOPERATIVE FINDINGS and RECOMMENDATIONS stay prose (#324,
   correct) and their `1./2./3.` slots become controls — but the S2 PDF path derives
   them UNLABELLED, losing the heading→`procedure.findings`/`procedure.recommendations`
   association the DOCX path (#319, `IDENTICAL_LIST_MAPPING`) had. The model has
   nothing to map a bare slot to.
2. **DD / DT not matched.** The labels are `DD (dictated)` / `DT (transcribed)`; the
   `VISIT_METADATA_LABEL_CONCEPTS` regex expects a bare `DD`/`DT`, so they fall through
   to `null` instead of `visit_metadata.dictated_at` / `.transcribed_at`.
3. **PREOPERATIVE DIAGNOSIS / INDICATION dropped.** #324's row-spacing writing-gap
   threshold (2.2 rows) left it prose — its gap beneath (≈1.9 rows) is below the bar
   that keeps a dense-body title out. So it is not a fillable control.
