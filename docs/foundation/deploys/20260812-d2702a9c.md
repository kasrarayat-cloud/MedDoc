## The one-line version

**Nothing but the image ids.**

This is a code-only deploy of a seam that does no work. `BILLING_ENFORCED` is
set nowhere — not in `.env`, not in either compose file, and **verified unset in
both running containers** (`printenv` exit 1, app and worker) — so neither
`admitVisitOrThrow` nor `chargeVisitUsage` reaches a database at all.

⚠️ **AND EVEN IF THE FLAG WERE ON, THIS CHANGE WOULD WRITE THE SAME ROW B6
WROTE.** `ledger_entries` holds **0 rows** in both environments, so every
practice's wallet is `{paid: 0, promo: 0}`, and `splitCharge` degenerates to
exactly one draw on `paid` for the whole charge. A named gate arm asserts that
degeneration. There is no population in which this change can behave differently
from its predecessor.

### ⚠️ Rows 4, 7, 20 and 21 are this deploy's own assertions

Every other row is the standard clinical-count set, carried because a deploy that
moves a visit, patient or signature count has done something nobody asked for.

- **Row 20 is checked INSIDE the running containers, never on the compose file.**
  `docker-compose.qa.yml`'s `${MOCK_AI_CALLS:-true}` is the recorded precedent:
  the file read as safe and the containers were not, because a `${VAR:-default}`
  inherits from the shared `.env` that production needs.
- **Row 7 is what row 20 failing would LOOK like.** Two independent statements of
  one invariant — one structural, one behavioural — because the structural check
  is the one that can be true about the wrong universe.
- **Row 4 is the one three rulings depend on.** 89(e), 90(d) and 94(e) all rest
  on `ledger_entries` being empty, and B7 step 3 is the item that will
  deliberately end it. Not this one.
- **Row 21 is new to this declaration.** This change altered code the QA stack
  also runs, so the honest scope of "did anything write a ledger row" is both
  environments, not just the one being deployed.

### On rows 9 and 10

`api_usage_events` and `ai_calls` are live counters: a visit processed during the
deploy window moves them legitimately. They are still declared exactly.
**A difference that is not in this declaration is THE FINDING** — and if either
moves, the correct response is to identify the visit that moved it, not to reach
for *"the deploy window explains that"*.

rows 3, 5, 6, 8, 11, 12, 13 moving at all. A co-tenant changing. Fewer than 9
