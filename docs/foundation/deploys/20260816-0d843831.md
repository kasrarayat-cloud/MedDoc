## WHAT SHIPS

Rulings **#113** · **#116** · **#116-b** · **#117** (the gate this waited on) ·
**#119** (new, provisional).

`pdf-generator.ts` (pdfkit) is **deleted, not hidden**. Every styled visit PDF
becomes LibreOffice's render of `generateVisitDocx`'s bytes — the route the
pre-sign preview has always taken. Five callers dispositioned: three converged
(`export/pdf`, `patients/[id]/export`, `settings/export-data`), two deleted
outright (`sign/route.ts`, `export/email/route.ts`) because they rendered a
patient's signed note only to read `.byteLength` into a write-only column.

⚠️ **THE PAYLOAD IS LARGER THAN THIS DECLARATION'S SUBJECT, AND IT IS SAID
BEFORE THE DEPLOY, NOT DISCOVERED AFTER.** `0d843831` is the first deploy since
`012ea04c`. Everything between them is this PR plus the F-117e test-only work
already cited on `a66602ca` (zero production files — `docx-generator.ts` was
verified byte-identical to `main` by its author). **So the production-code delta
in this deploy is F3 and nothing else**, and the rows below are written to judge
F3. *"I deployed `main`" is not the same claim as "I judged what I deployed."*

## THE DECLARED DELTA

### MUST change

1. **`pdf-generator.ts` is absent from the shipped worker image.** `pdfkit` is
   no longer imported by application code.
2. **`visit-pdf.ts` is present in the shipped image** and is the only styled-PDF
   entry point.
3. The **34** non-form-only styled visits' PDF exports no longer carry the
   `QUILLMD` wordmark — **ruling #119, declared here so the post-deploy
   comparison cannot absorb it as noise.**
4. The **1** unsigned form-only styled visit's PDF gains the per-page draft
   footer. A **tightening**.

### MUST NOT change

5. **Clinical counts, all four.** `transcribe_visits` **45**, signed **27**,
   `transcribe_md_patients` **32**, `visit_deliveries` **95**. ⚠️ *A deploy that
   moves a visit, patient or signature count has done something nobody asked
   for.*
6. **No `audit_logs` row is rewritten.** `EXPORT_*` counts stay at 5 / 1 / 35 /
   42, and `EXPORT_EMAIL_SENT` stays at **0**.
7. **Migrations stay at 104 applied, 104 in repo.** This deploy carries none.
8. **Word exports and the pre-sign preview are byte-unchanged.** Both have
   always been `generateVisitDocx`; this item only stops the PDF being a second
   opinion. **The watermark loss must NOT appear on either** — if it does, #119
   was executed wrongly and a wordmark reached the doctor's Word file.
9. **Co-tenants unchanged:** `app` 307 · `admin` 404 · `quillmd` 200 · `www` 200
   · `pro` **410** (deliberately retired).
10. **The signed form-only cell stays chrome-free** (8 rows) and the signed
    standard attestation text is unchanged — #117(b)'s shipped string governs.

### ⚠️ MUST BE VERIFIED SPECIFICALLY — the new hard dependency

11. **Gotenberg is now load-bearing for every styled PDF, with no fallback
    builder** (accepted on the record by #113 and #116(c)). The
    `meddoc-pro-gotenberg-1` container must be **healthy** after the deploy, and
    a conversion must actually succeed — a healthy container says nothing about
    whether anything can reach it.
12. **A failure must be LOUD** (RC-3): `convertDocxToPdf` returns a coded reason
    and `visit-pdf.ts` checks for a `%PDF` magic number, so a mis-proxied `200`
    carrying HTML can never be streamed as `application/pdf`.
