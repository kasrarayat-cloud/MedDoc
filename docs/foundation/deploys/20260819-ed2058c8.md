## ⚠️ THIS IS NOT A READ-ONLY CHANGE, AND AN EARLIER DRAFT OF THE LEDGER SAID IT WAS

Found by F12-d's adversarial pass. `emAppliesToVisit` **drives writes**:
`page.tsx:656-667` writes `emScoredCode` on render when it returns true,
`sign/route.ts:578` freezes `cptCodes.em.signedCode`, `rescore-em.ts:118` writes
`emStale`.

> **A rollback is therefore NOT a clean inverse.** A row that acquires a
> `signedCode` while this is live keeps it, and the rolled-back predicate then
> suppresses that same row — a signed record whose stored row carries a code its
> document refuses to print.

It is written here rather than in the rollback section because it changes what
the numbers below mean: the E/M state counts are MUST-NOT-CHANGE **for the
duration of this deploy**, and they are expected to move later as doctors work.
