### ⚠️ ASSERTION 8 IS THE ONE THAT MATTERS, AND IT IS NOT A FORMALITY

B6 introduces **the first writer this table has ever had**. If any ledger row
exists after this deploy, something is calling `commitVisitCharge` that ruling
90(e) says nothing calls — and because `ledger_entries` is append-only by
trigger, **that row can never be deleted, only offset**. A non-zero count here
is not a discrepancy to explain afterwards; it is a defect that has already
become permanent.

It is also what keeps ruling 90(d)'s retrofit window open: the `pricing` column
was free to add precisely because the table is empty, and assertion 8 is the
statement that it still is.

### ⚠️ AND THE CLINICAL COUNTS ARE NOT OPTIONAL ROWS

AGENTS.md: "a deploy that moves a visit, patient or signature count has done
something nobody asked for, and the only way to know is to have written the
numbers down while they were still true."

## THE EXPECTED READING, STATED PLAINLY

**Beyond the image ids, one migration row, one column and one CHECK, nothing
about the running system's behaviour should differ at all.** No code path
changed: the only new runtime surface is a module with no callers, and the only
schema change is to a table nothing reads or writes.

If anything in the MUST-NOT list moves, **that is THE FINDING**, whatever
explanation is available after the fact.

## Rollback

⚠️ **Tag against the RUNNING image ids BEFORE `deploy-prod.sh` recreates
anything** — session 01 cut B5's tag late and it survived on luck, because a
dangling image is exactly what `docker image prune` deletes and preflight runs
one. `deploy-prod.sh` does **not** do this for you.

    docker tag 5483ff331dd7  meddoc-pro-transcribe-md:pre-b6-20260811
    docker tag 7aabd4cc69c6  meddoc-pro-transcribe-md-worker:pre-b6-20260811

**The migration is not reversed by an image rollback**, and it does not need to
be: a nullable column and a CHECK that only constrains `kind='usage'` rows are
inert against a `ledger_entries` that holds none and a codebase that writes
none. Rolling the image back leaves the column in place, unused.
