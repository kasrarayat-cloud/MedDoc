## ⚠️ FILED DEBT — the audit gate is pinned to a RETIRING endpoint

**Filed 2026-09-04, before the deploy, as the standing rule requires. Built
immediately after it.**

`scripts/audit-gate.mjs:169` shells out to `npm audit --json`, which reaches
`registry.npmjs.org/-/npm/v1/security/audits/quick`. npm itself prints
*"This endpoint is being retired. Use the bulk advisory endpoint instead."*
on every invocation, and on `80b04992` it answered **500**, so the report
carried no `vulnerabilities` object and the gate correctly refused with
`CANNOT TELL`.

**An instrument pinned to a deprecated endpoint is a scheduled outage.** The gate
did the right thing — a broken instrument and a clean tree produce the same
silence, and it declines to confuse them — but it will keep doing the right thing
about the wrong question until it stops asking through a retiring path.

**⚠️ THE DEPLOY ITSELF DID NOT NEED THE CARRY-FORWARD.** The job was re-run once
the CI run settled and came back **`success`** — the 500 was transient, so
contingency 1 applied and no evidence was carried forward. The predicate had
been established anyway and is recorded here because it cost nothing and would
have been needed had the endpoint stayed down: `package-lock.json` is
**byte-identical** (`a624dbc04b50805398ba5ba5509b5bf6afc5ecd3`) at the green
PR-head run and at the merge commit, and the ENTIRE tree diff between them is
two markdown files. Green run: `100842565321`, completed `2026-09-03T22:49:11Z`.

**The fix, to be built directly after this deploy:**

1. Move to npm's **bulk advisories** path rather than the quick endpoint.
2. **Retry with backoff** on transient registry failures (5xx, timeouts), so a
   single 500 does not red a required check.
3. **Keep `CANNOT TELL` fail-closed** after the retries are exhausted. A genuine
   outage must still block; the point is to stop treating a one-second blip as
   an outage, not to stop failing closed.

This is a debt-payment task, not a nice-to-have: the gate is REQUIRED, so its
availability is the deploy path's availability.
