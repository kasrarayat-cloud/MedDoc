This change continues the preserved Corti adapter/context-recovery work and the
bounded output-permission assessment. It prepares the native synthetic workflow;
this document is not evidence that installation or a fresh provider test ran.
The original Rowan encounter, generation receipts, blank Word and failure remain
unchanged. Private execution evidence is retained separately.

The demonstrated generation failure was the complete sentence “The cause of
these symptoms has not been established.” The legacy note-wide pointer/negation
reader interpreted its “these” and “not” as governing the entire source. Removing
the fictional banner does not resolve that failure. New jobs freeze the v11
source contract; historical v10 jobs retain their original interpretation.

patient labels and quoted examples remain held, and physician-time destinations
require their own numeric source binding. Composite visit/status, Assessment and
concise E/M-basis meanings require an explicitly reviewed narrative definition
version; no validator silently changes an approved atomic definition.

required both comma-separated synonyms. The repair requires independent matching

catalogue, skip other ancestors or add an expected-code exception.

activation timestamp, with the global existing ICD provider preserved. Existing
