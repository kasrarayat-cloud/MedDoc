Instrument Panel
the shell, and the margin inside it

The idea: the admin surface is a calibrated instrument, not a dashboard — a handful of authoritative readouts, hard stops you can see, and a margin control whose positions are integer pairs, so a decimal is never entered and never stored. Banned myself from KPI card rows, grids, gradient heroes, donuts, sparklines, emoji, any multi-panel “everything at once” layout, a chronological list as the spine, and a practice data-grid; one subordinate table exists in the whole document (the append-only history) and no screen state shows more than seven numeric readouts. Token broken: the radius scale. Shipped Rounds radii are 9 / 12 / 18px, which read as soft app cards; a machined faceplate needs 5 / 7px, so every corner here is tighter than the product's. It is one variable — --r — and somebody should decide whether “instrument” is worth a second radius scale before this ships. Colour, type and status vocabulary are unbroken; #5b5bd6 is used only as fill and edge, never as small text.

The cause is stated in sentences, not in a grey box, and the consequence is the sentence that matters: metering runs, nothing is charged.

PLATE 03 The rate editor  ·  live — click a detent, or step the integers

This one works. The hard part of this direction was that a ratio is two integers while the bound is on the quotient. It is solved by never accepting a decimal anywhere: the coarse control is a ladder of detents, each of which is a pair; the fine control is two integer steppers. The quotient is computed for the eye and for the CHECK, and it is labelled as derived. Step the numerator past 5 / 1 and the carrier pins against the stop and the panel refuses — you can feel where the range ends.

PLATE 06 Per practice  ·  one channel at a time

Not a grid of practices — a channel selector and one set of readings, read precisely. Five numbers on the screen. The rate that applied is a stamp, not arithmetic: the panel prints the platform_rates id the ledger row carried and the pair that row held, and it never multiplies anything, because a screen that re-multiplies is a second implementation of the rate. And the wallet is two vessels with a gap between them — promo and paid never become one number.

PLATE 07 The remaining states

Every one of them is the instrument saying something specific about itself. Loading is a needle hunting for a position; empty is a scale with no channels on it; refused is the panel declining to admit the route exists at all, which is what a 404-gate means.

Loading
The needle is hunting. No number is shown while it is moving — a half-settled instrument is worse than a blank one.
Empty
No practices metering
The scale is calibrated and armed; there is nothing on it yet. Distinct from no rate configured, which is the control having no position.
Error
Reading unavailable
The metering store did not answer. No value is shown, and no stale value is shown either — an instrument that keeps displaying its last reading is the failure this panel exists to avoid.
RETRY  ·  trace 7f2a1c9e
Refused  ·  403 / 404-gated
Not found
Entitlement is re-read per request and the route answers 404, not 403, so its existence is never disclosed. There is no panel to draw here, and drawing one that says “forbidden” would leak the thing the gate is hiding.
Stale  ·  admin session older than 12h
Session past 12h — controls locked, readings still shown
Readouts stay legible because reading is not the risk. Every control is dead until re-authentication: the carrier will not move, the steppers do not respond, and Append row is inert.
ADMIN SESSION12h 41m — EXPIRED
Designer's notes carried forward
  • The ratio problem, solved without a decimal anywhere. The input space is ℤ × ℤ⁺; the constraint is on ℚ. So the coarse control is a ladder of detents that are themselves integer pairs, the fine control is two integer steppers, and the quotient exists only as a derived readout and as the CHECK's argument. There is no continuous slider and no numeric field that would accept 1.5.
  • The scale is logarithmic in the quotient and says so. On a linear scale everything useful would crowd into the first eighth of the rail; on a log scale 3/2 lands at 25% and 2/1 at 43%, which is where the operator actually works.
  • Two hard stops, one visual language. The bounds are physical end caps with hatched out-of-range stubs beyond them; “retroactive” on the effective-from rail is drawn as the same kind of stop. Both are things the mechanism will not do, and they look alike on purpose.
  • Health uses the shipped words only — HEALTHY · DEGRADED · DOWN, as three lamps on the faceplate edge. In the unset state they tell the same story the instrument does: metering HEALTHY, ledger DEGRADED, wallet DOWN.
  • One token broken: radius. --r: 5px and --r-lg: 7px against the shipped 9 / 12 / 18px. The softer scale reads as an app card and undoes the machined feeling that carries this whole direction. It is one variable to revert if the answer is no.
  • Not decided here, and it is a real question: whether µ$ is the unit an operator should read, or whether the panel should also print dollars. This direction shows µ$ only, with the conversion engraved once, because every additional derived number is a place the screen and the ledger can disagree.
