Direction — Control Room

ADMIN SHELL + ADMIN-4 MONEY VIEW · 2026-09-09

The idea: the console is an instrument panel that is read continuously rather than visited — four destinations that each report their own condition, and a money view that states the platform's vital signs at a glance, with NO RATE CONFIGURED rendered as a system that is deliberately not armed rather than as an absence. Panels butt together on hairlines so the whole posture is in one screenful; nothing worth knowing is below the fold.

  • no hero numberthe rate never dominates; it sits in a matrix with everything else that is true

  • no chronology spinehistory is section 05, inside one panel; the spine is the matrix
  • no serif, no paperthe paper/ink half of the token set is untouched — this surface is never a document
Tokens broken — for the owner to judge
  • mono everywheretokens reserve mono for IDs and timestamps. Here it carries the whole console: a control room is read down columns, and column alignment is the instrument. Cost: less type contrast than Rounds.
  • radius 3pxtokens ship 9 / 12 / 18px. Rounded panels cannot butt into a seamless matrix, and the seam is the layout. Cost: visibly not the clinician skin.
  • amber = unarmedwarning amber is re-cast as a deliberate condition, not a problem; red stays for genuine failure and refusal. Two words, two colours, no overlap.
