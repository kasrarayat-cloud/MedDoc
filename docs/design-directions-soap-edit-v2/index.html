10 patterns paradigms

v1 explored ten ways to click into editing. Kasra read it as one paradigm shown ten times. v2 explores ten paradigms — different mental models for what “editing a SOAP” even is. Voice, diff‑review, chat, source mode, an outline, a clinical form, transcript anchoring, a timeline scrub, Notion blocks. Each mockup deliberately uses a different visual language so the differences read at a glance; the winner gets re‑styled to production tokens later.

Why v1 collapsed

Every v1 pattern was “textarea opens differently.” Hover pencil, header pill, click vs double‑click, sticky bar — all variations on the same paradigm: render prose → swap to textarea → save. Kasra’s read was right: “mostly similar to each other.” v2 throws out that frame.

05

Outline mode

Toggle the SOAP to a structured outline of short bullets. The doctor edits bullets — short fragments, not paragraphs. On save, the AI re‑expands each bullet to prose. Same content, lower cognitive load: nobody types a sentence when six words will do.

06

Template‑fill · structured fields

08

Transcript‑anchored editing
