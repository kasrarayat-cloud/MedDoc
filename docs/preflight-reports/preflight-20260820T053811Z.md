run naively it produces a **clean-looking all-clear**:

    → (no output)

**That zero is worthless.** Controlled by asking the same command for *any*
output at all:

    journalctl -k --since "24 hours ago" 2>&1 | head -4

            Users in groups 'adm', 'systemd-journal' can see all messages.

The journal is **inaccessible to this user**, so "no OOM kills" and "no kernel
messages of any kind" are the same output. This is AGENTS.md's *positive-control
every zero* rule catching the exact shape it exists for — a broken check and a
clean system are indistinguishable — and the honest disposition is
**cannot-tell**, never a pass.
