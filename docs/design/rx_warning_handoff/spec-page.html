§ 02

Anatomy

The card hierarchy matches how a physician's eye moves: severity → action → facts → context.

1

Severity pill + field label

Mono-case CRITICAL badge, color-coded by level. Right of it, the field being flagged (Rx · Line 2) — so the physician knows where this attaches without scanning the whole slip.

2

Headline — one clause, serif

"Cannot verify medication." The only sentence the physician should need to read to know this row is unsafe.

3

Primary action — the only red sentence

Ban icon + Do NOT prescribe until confirmed. The single highest-contrast line, boxed so the eye catches it even in peripheral vision. Reserving red here keeps the rest of the card readable.

4

Transcribed → guess

Facts, not prose. Heard: "abirrobing" on the left, phonetic guess on the right. Mono type signals raw/unprocessed; the guess is purple — the system's tentative proposal, never a commitment.

5

Patient-specific risks

Each bullet names a current med and the clinical outcome. Two lines, two beats. Designed to be read in ~3 seconds total.

6

Next step — dashed tile

Says what to do with this warning, not just why it exists. Dashed border signals "procedural, not blocking" — the card above already blocks.

7

Details — collapsible rationale

The original paragraph lives here. Collapsed by default because 95% of physicians won't need it; one click away for those who do. Citation line at the bottom ties back to the transcript timestamp.

8

Resolution actions — per severity

Buttons shift with severity so the only paths offered match what's clinically appropriate.

Critical → Edit medication · Call provider · Override & sign anyway

Warning  → Edit · Call provider · Acknowledge

Info     → Dismiss

Critical warnings never offer a passive dismiss. Overriding is a deliberate action that opens a confirmation modal and is recorded in the audit log.
