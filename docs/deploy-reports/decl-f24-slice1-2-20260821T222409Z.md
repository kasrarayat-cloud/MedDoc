# §2.5 DEPLOY DECLARATION — F24 Slice 1 + 1b + Slice 2

**Written and committed BEFORE the act.** This is a **RENDERING** change. No
migration, no schema change, no flag.

## WHAT IS SHIPPING

**Slice 1 + 1b** (already on `main`, `8ae016ff`) — the generator emits a
header matching the rows it dictates; widen-on-parse gated on header evidence;
`caption_not_found` replaces an unanswerable question.

**Slice 2** — ONE markdown row reader, five callers. Four strict matchers and
one tolerant one disagreed about a row carrying a trailing annotation after its
last pipe: the fill read it, every other surface skipped it, and the EHR paste
leaked it as raw markdown.

## ⚠️ THE RENDERING CHANGE, NAMED

Both export renderers now parse a row the strict matchers rejected. For such a
row the output CHANGES BY DESIGN — that is the defect being fixed:

| surface | before | after |
|---|---|---|
| EHR paste | raw markdown line between two flattened rows | a flattened row, annotation carried in the tail |
| `word/document.xml` | a literal paragraph of pipes | a real table row, annotation as an extra cell |

## MUST NOT CHANGE

- **Every existing document renders byte-identically.** Proven on all **49**
  production notes, both surfaces, with a control on a production-exercised path
  (EHR moves 15 of 49; DOCX moves 24 of 49 under a deliberate mutation).
  Re-taken after every subsequent edit.
- **visits 50, SIGNED 32, patients 37** — a rendering deploy that moves a
  clinical count has done something nobody asked for.
- fill manifests **2**, frozen pointers **1**, CERTIFIED **1**.
- applied migrations **106 → 106** — this deploy carries none.
- co-tenant status per host, `pro.quillmd.com` **410**.

## ⚠️ THE NATIVE PATH IS UNTOUCHED — ASSERTED, NOT CLAIMED

The frozen-manifest **SERVE** path must not acquire an opinion about markdown:
a rendering change must not alter what a signed record hands back.
`gate-f24-slice2-one-row-reader.test.ts` asserts **zero** `markdown-row`
imports in `native-export.ts`, `fill-engine.ts`, `sign-freeze.ts`,
`note-identity.ts` and `visit-docx-source.ts`, and pins the caller set at
**exactly five** — a sixth is a decision, not a drift.

**The distinction is CREATE vs SERVE.** `bridge-fill` BUILDS a manifest and is
a legitimate caller; the five above SERVE stored bytes.

## WHAT THIS DEPLOY DOES NOT PROVE

- **The changed rendering is UNEXERCISED by any existing document** — 0 of 49
  production notes carry the annotated shape. Byte-identity is exactly the point,
  and it means the new behaviour ships unobserved in production until L4 emits
  that shape. Named here rather than discovered later.
- **F24-caption-validation stands open** — 20 of 45 tables remain uneditable
  when bilateral.
- Slice 3 (addressing tuple + native-fill structured edits) is not in this ship.

## THE FINDING RULE

A difference this declaration does not name is THE FINDING, whatever its
explanation sounds like afterwards.
