## ⚠️ TWO BASELINE CELLS ARE NOT NUMBERS, AND THAT IS THE HONEST READING

`frozenFillManifestId` and `noteSha256` **do not exist in production yet** —
this deploy creates them. The baseline query returned EMPTY for both, and an
empty cell is exactly what a broken instrument returns, so it is named here
rather than printed as a blank or rounded to a comforting `0`.

Positive-controlled against `information_schema`: both columns read 0, and a
control column (`transcribe_visits.status`) reads 1 — so the query works and
the absence is real. **After the migration both must be 0**, which is a
different claim from "the query answered 0 today".
