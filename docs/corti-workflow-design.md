# Coding review and Word appendix reference lock

The existing QuillMD clinician document and Coding tab are the dominant design
reference: their typography, teal action color, border-separated rows, evidence
quotes and mobile single-column layout remain the visual target. The existing
document review footer supplies the explicit save-before-approval sequence.
The original-format download supplies the download button pattern.

Refero's bundled `copywriting.md` (clear next action, factual status) and
`craft-details.md` (visible labels, focus and disabled controls) supplement these
product references. Refero MCP is unavailable in this session. No generated
imagery or new visual style is needed for this extension.

Each selected row shows code, verified dated description or precise unverified
status, all returned evidence spans and accept/reject selection. Original provider
wording is diagnostic detail. Held rows remain visible with disabled acceptance.
Unselected candidates have no review controls. A replay banner identifies the
synthetic candidate and preserves the original failure. Save and explicit approval
remain separate; unsaved edits disable approval/export and polling preserves them.

After approval, the Coding tab offers Export with codes. It downloads a distinct
Word file; the original-format action remains unchanged. Appendix eligibility is
rechecked server-side. Desktop and mobile checks must cover overflow, evidence,
holds, unsaved changes, approval and an actual download.
