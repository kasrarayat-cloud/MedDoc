# Orders with later collection or performance

A complete source statement can place an order in the current encounter and
schedule its collection or performance later. A whole plan fact may consequently
carry a `future` timing annotation while retaining both roles verbatim. The
current-only investigation completeness check previously rejected that complete
fact as an omitted order. A live retained test exposed the rejection before the
first independent checker request.

Newly queued generation uses `positioned-order-event-roles-v23`. The bounded
source reader recognizes complete present order placement with an explicit
future collection or performance complement. It includes the existing complete
family-history indication form without assigning that disease to the patient.
Only a whole, affirmed patient plan fact can use this timing-role rule; its
original annotation and every source word remain unchanged.

This source classification supplies no clinical truth or destination permission.
Patient, clinician, encounter and Plan ownership, fact issues, polarity, full
span coverage, approved field timing and the independent checker still govern.
A current-only destination continues to reject a future-labelled whole fact.
An order cannot replace documented noncollection, nonperformance or absent
results. Conditional, quoted, retracted, foreign and unrecognized source forms
cannot acquire this timing-role exception.

Stored v21/v22 jobs keep their original behavior. A local replay of retained
facts and assignment selections can prove that the deterministic false hold is
closed, but old checker responses that saw the held preview remain conflicts.
They must not be replaced, waived or reported as a newly accepted generation.
The failed live encounter remains preserved and unapproved. Actual live
acceptance, persisted coding review and Word downloads are separate gates.
