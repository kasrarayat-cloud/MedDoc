# Typed notes, reviewed voice and colonoscopy generation

This narrow private workflow change follows the owner's September21 request.
It preserves the original colonoscopy form, mapping version2 and the previous
manual compatibility exports. Those exports prove form compatibility; they do
not prove AI accuracy. The protected execution evidence lives at
`rebuild/.runtime/typed-voice-20260921/`.

## Interface reference and decisions

The reference is the installed QuillMD document screen: existing typography,
controls, source panel, answer review and separate Coding tab. The Refero
skill's direct-build exception applies to this explicit repair of the existing
screen; no new visual language or dashboard is introduced. Its bundled craft
guidance informs visible labels, inline status, focus and pending states.

- Show source notes and voice controls before the answer draft. A new document
  may begin without notes so voice users do not need a placeholder such as Test.
- Saving is explicit. Unsaved notes, answer edits and transcript corrections
  prevent another action from silently using older saved content.
- Recording begins only on an explicit action. Playback and discard precede
  consent and priced submission; microphone errors have actionable messages.
- New transcriptions preserve raw output and require an explicit reviewed
  append/replace decision. Historical jobs retain their original append policy.
- Generation quotes and queue admission bind the same saved notes revision.

## Generation boundary

The underlined-tab form uses complete source evidence units with exact offsets.
The provider selects offered units for the actual approved questions. It does
not rewrite the form as SOAP or compose unsupported clinical facts. Whole-unit
selection protects negation and context; explicit inline correction retains the
original evidence while using the corrected value. Ambiguity remains reviewable.
Existing placeholder, SOAP table and WM IOV source contracts remain separate.

covers24 logical fields/28 physical anchors, including paired inline fields,

## Verification and operational boundary

Focused offline tests cover current-source admission, duplicate submissions,
raw transcript retention, explicit application, recorder controls and complete
source binding. Required branch/merged CI and finished-diff internal refutation
precede private installation through the preserving activation adapter.

Live qualification is separately bounded to two generation requests and one
transcription of locally synthesized fictional facts, under displayed maximum
reservations totaling no more thanUSD1. Original outputs, corrections, mapped
answers, exported hashes and immutable provider/settlement records are retained.
An extra request requires a demonstrated failed path and a bounded repair.
Configured-rate arithmetic is not invoice reconciliation. No old operation is
replayed, and no prior provider-import snapshot is rewritten.

The final protected report distinguishes live results from offline fixtures,
render inspection from native Word acceptance, and synthesized speech from the
owner's natural microphone test. Production activation remains out of scope.
