## Actual change

The shared source reader records a bounded explicit patient chain separately
from field ownership. It requires the complete source to fit the recognized
relations: an existing explicit patient onset, a literal re-mention of that
topic, complete patient statements and nominal denial lists, existing named
source statements, and a complete named Plan with its same-patient timed
follow-up. An unrecognized subject, predicate, relationship, changed pronoun or
source shape removes the additional relation. There is no people-name blacklist
and no implicit patient anchor for retained note8.

Only exact source spans localize `ago`, nominal-list `or`, the complete
`nonsmoker` state and the named Plan's infinitive `to`. The new route is a narrow
literal ASCII grammar; normalization never grants ownership. Existing visible
scope/correction guards remain. No source text or evidence offset is rewritten.
The complete nonsmoker statement can separate two source topics without becoming
a printed option. Actor provenance supplies no clinical write destination.

Additional independent-topic use is limited to unique unscoped text destinations
with the existing actual labels for Allergies, Examination, Assessment,
Medications and Plan. Context equal to the same imported label is permitted;
another person, side or section is not. The original unowned patient-history
block still needs complete selection. Complete Plan selection retains both
instructions in source order. Generation, stored display, save and finalization
use this same reading, including forced historical supported records.

This is structural source attribution, not a general clinical contradiction
classifier, medication ontology, clinical interpretation or free-form pronoun
resolver. The narrow denial-list check also withholds a literal singular/plural
re-mention of the onset topic. It does not claim to detect clinical synonyms.
