# SOAP form entry reference lock

This is a small direct build for invited clinicians within the existing form library. Its purpose is to make four-section SOAP documentation available through the current persisted mapping, source review, finalization and Word export workflow.

Skill: [refero-design](/opt/meddoc-pro/.agents/skills/refero-design/SKILL.md). Live Refero tools were unavailable in the tool catalog. Research before implementation used the bundled craft-details reference for explicit form labels and unchanged keyboard focus, copywriting for calm concrete next actions, and the retained [notes workflow reference lock](../notes-workflows-20260927/UI-REFERENCE-LOCK.md). Primary product reference: the existing dashboard form library; secondary references: template_upload's split form/aside and workflow steps, and template_detail/encounter_detail's mapping and answer review.

Locked choices: one text action beside the existing Upload form action; the existing form-section, split, aside, step-list and form-footer patterns for department selection; native labelled department select, required CSRF and the established duplicate-submit control. Keep current typography, tokens, spacing, assets and focus styles. The original DOCX is four ordinary two-column rows with no fixed height, signing field or clinical content. No new design system or decorative screen.

The action is Use SOAP note, followed by Review SOAP form. Copy says that documented assessment/plan is required, missing information needs review, and the original/mapping are retained. It does not promise independent diagnosis or automatic note completion. Permission failures show the existing clinic-access recovery direction.

Validation: authenticated HTML, an MFA administrator positive control followed by denied SOAP requests, real persisted cross-department negative controls, and rendered desktop/mobile entry checks. Worker/export assertions are separate from visual entry acceptance; synthetic automated checks do not qualify provider usefulness or human microphone/native Word acceptance.
