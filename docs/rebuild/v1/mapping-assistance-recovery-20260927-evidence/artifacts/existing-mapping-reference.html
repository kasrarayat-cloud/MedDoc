How answers are written

  • Printed options: one option, exactly as printed.
  • Several printed options: tick each one that applies.
  • Checkbox: ticked, or left empty.
  • Table rows: one row per line, cells separated by “ | ”.
  • Signature and initials: signed by hand on the printed form; never filled.
