assembled context above the limit refuse visibly. A caller-supplied context is

Same-source assistance replacements preserve an existing complete context only
when the newly resolved locator dictionary exactly matches the original locator,
including part, slot, target and fingerprint. A descendant alias can be accepted
by the existing overlap policy with its own derived context; it does not inherit
the old context. A different existing field reference is refused. An early test
incorrectly expected every descendant alias to be rejected; both failed test
attempts and the corrected binding proof are retained.

HTML `maxlength` counts UTF-16 units, unlike Python's code points. Its ceiling is
2,000 units so a valid 1,000-code-point value containing astral characters is not
silently shortened in the browser. The server enforces the 1,000-code-point bound
and displays an error for oversized input. These are deliberately different units.
