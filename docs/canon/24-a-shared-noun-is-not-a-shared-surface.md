## A SHARED NOUN IS NOT A SHARED SURFACE

**Standing 2026-08-24. Found by a pass over a fix, on the arm that looked like
coverage.**

> **ENUMERATE READERS BY CALL SITE, NEVER BY VOCABULARY.**

A branch stripping Word's `Choose an item.` placeholder noted *"three readers do
that today."* The same diff touched **five**, and a **sixth** was unfiltered:
`semantic-mapping/index.ts:291 → :355` put the placeholder into the
mapping-proposal payload, telling the model it was a genuine clinical option on
all 28 single-selects of the certified twin.

⚠️ **THE ARM THAT APPEARED TO COVER IT IS THE FINDING.** The gate carried an arm
titled *"never OFFERS the placeholder to the model"* — and it drove
`listEditableFormControls`, the clinician's **EDIT DOOR**. A different surface
that merely also has a model on the other end.

**Two surfaces shared one phrase — *"the model"* — and the phrase is what hid the
gap.** This is canon's *title narrower than what it measures*, **inverted**: the
wider direction is worse, because a name that reads as coverage stops anybody
looking.

**The practice:** when a value must be excluded, filtered or redacted, list the
**call sites that read it** — `grep` the symbol, then the column, then the
literal — and check each against the rule. A count of readers taken from memory
or from a noun ("the model", "the export", "the client") is a vocabulary
inventory, not a coverage claim.
