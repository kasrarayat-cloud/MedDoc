# Reusable answer definition review

Reference lock: the current `rebuild/templates/template_detail.html` and
`template_preparation.html`, using the existing `base.html` and `app.css`.
Refero MCP research is unavailable in this environment. The retained product
screens supply the concrete references for this functional addition.

The review keeps the existing page heading, three-step list, notices, labelled
form controls, original-file download and explicit version approval. It adds no
visual system or CSS. The original document destination is read only. The
proposer's result, independent check and physician corrections remain distinct.
Every definition requires review of its meaning, type, unit, choices, subject,
timing, polarity and constraints. Signing protection is displayed at its field.

Pending preparation has no editable definition form. Status reconnects without
resending provider requests. Once results exist, unsaved changes block approval
of older retained values and use the existing navigation/undo protection.
Approval creates a separate reusable version; earlier approved versions and
documents retain their original behavior. Evidence remains separate from the
concise clinical answer in the subsequent document workflow.
