## Recommendation: cleanup cadence

- **Weekly:** `docker builder prune -af --filter "until=24h"` (the build cache is the main growth driver — ~10–20 GB/week under normal build activity).
- **Monthly:** `docker image prune -af --filter "until=72h"` + `npm cache clean --force` if `~/.npm` >2 GB.
- **Quarterly:** Tier 2 sudo pass (journal + apt).
- **On red preflight:** Re-run this exact reclaim sequence; the preflight skill auto-prunes >30 GB build cache.

The `until=12h` filter for build-cache prune is aggressive but safe — it preserves anything used in the last 12 h, which is more than long enough to cover an active dev session. Use `until=24h` for less aggressive routine cleanup.
