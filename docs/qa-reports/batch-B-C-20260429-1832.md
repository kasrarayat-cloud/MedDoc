### 🟡 User-judgment deviations (5)

These are deliberate choices the Component Builder made; the lead surfaces them so the user can confirm or revert before D+E.

1. **Dropped `§ Home / Today` mono breadcrumb prefix** in dashboard's eyebrow row. Now reads "Today" alone. Reason: the legacy `§`-mono breadcrumb visually clashes with `.qm-cl-eyebrow` (sage-deep ALL-CAPS). Mockup eyebrow is plain ALL-CAPS. Same change applied to `StatCard` labels.

3. **`<em>` accent color**: violet `var(--accent-bright)` → `var(--sage-deep)` in PageHeader title and EmptyPatients heading. Reason: warm-palette consistency.
4. **`pendingReview > 0` subtitle text color**: `var(--amber)` → `var(--amber-deep)`. Reason: deep variant exists inside `.qm-cl-app` scope and contrasts better against cream.
5. **icon-rail `.qm-cl-active::after` dot** renders next to the active nav icon (per `globals.css` definition). Mockup's `dashboard.html` shows this dot; mockup's `visit-detail.html` shows a stripped-down nav-item without the dot. Implementation matches the design-system baseline.
