C1Patient birthYear defaults to age 30 when missing
apps/meddoc-pro/src/lib/data/patients.ts:483
birthYear: row.birthYear ?? new Date().getFullYear() - 30 — any patient with a NULL DOB silently becomes a 30-year-old in SOAP notes, letters, referrals, and realtime voice context. Medical safety issue.

Security posture — positives

OK Session isolation between app.quillmd.com ↔ pro.quillmd.com
Both use __Host-authjs.csrf-token with exact-host scoping. No cross-subdomain cookie bleed possible. HSTS preload set.
OK Auth gating universal across 44 API routes
41/41 unauth probes returned 401 (3 GET 404s were wrong-method probes). /api/health intentionally public.
OK Tenant scope universal

OK XSS on signup name field → not executed

OK No 5xx observed
